# Code of Conduct

## Our pledge

We want this to be a place where someone can report a bug in their second
language, ask a beginner question, or disagree with a design decision without
being made to feel stupid. Everyone participating — maintainers, contributors,
and people filing issues — is expected to help with that.

## Expected behaviour

- Assume competence and good faith. Ask what someone meant before deciding they
  were careless.
- Critique the change, not the person. "This loop can leak the job reference" is
  useful; "you clearly don't understand coroutines" is not.
- Respect that this project has opinions: native only, no telemetry, no new
  dependency without a reason. A pull request that argues with those is welcome
  to argue once, in an issue, with reasoning.
- Be honest about what you have not tested.

## Unacceptable behaviour

- Harassment, threats, or sustained hostility in any channel.
- Discriminatory comments about race, ethnicity, nationality, gender, gender
  identity, sexual orientation, disability, age, religion, or experience level.
- Sexualised language or imagery, and unwelcome attention of any kind.
- Publishing someone's private information without permission.
- Deliberately derailing threads, or reopening a settled decision to wear people
  down.
- Submitting code intended to harm users: backdoors, undisclosed telemetry,
  credential exfiltration, or anything that phones home.

## Scope

This applies in the repository — issues, pull requests, discussions, commit
messages, code comments — and in any space where you are representing the
project.

## Reporting

Report problems privately to the maintainer through the GitHub profile contact
or the private security channel in [SECURITY.md](SECURITY.md). Reports are read
personally and kept confidential.

Consequences scale with severity and history: a private word, a request to edit
a comment, a temporary block from the repository, or a permanent ban. The
maintainer is the final arbiter, and will explain a decision to the person
affected.
